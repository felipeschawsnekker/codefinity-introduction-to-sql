# Codefinity: Introduction to SQL

Exercícios de introdução a SQL, separados por assuntos estudados no Codefinity.

## Organização

- `retrieving_data/`: consultas e recuperação de dados.
- `filtering_data/`: filtros, incluindo verificação de valores nulos.
- `sorting_retrieved_data/`: ordenação dos resultados.
- `aggregate_functions/`: funções agregadas, incluindo `SUM`.
- `advanced_data_filtering/`: atividades de filtragem avançada.

As pastas reúnem consultas e desafios de estudo. Não foi validada uma execução conjunta em banco de dados.
